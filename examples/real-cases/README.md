# Real prompt outputs and case notes

These examples are selected from completed DirectorReady text-prompt runs. They show prompt preparation only; no image or video was generated as part of these examples. Names are replaced with “角色甲/角色乙” below, and internal project identifiers and audit data are intentionally omitted.

## Case 1 — From a story brief to a character prompt

**Before — short source brief:** In a contemporary family-drama story, a young adult woman appears at a funeral. The chosen visual direction is dark fantasy with a restrained palette. This is a short, privacy-conscious summary, not the full source script.

**After — accepted character image prompt:** The following is the accepted prompt text, with only the character name anonymized:

> 暗黑奇幻风格的单人人物主形象参考图，采用统一克制的有限色盘，画面表面干净细腻。纯白色背景，单独展示角色甲。身体正面朝向观看者，面部端正朝前，自然站立，双臂放松，双手自然下垂于身体两侧，手掌和手指清楚可见；从头顶到鞋底完整入画，四周适量留白。保留约二十岁成年女性的视觉年龄感，身形修长匀称，肩线平直，颈部线条清晰。面部轮廓清晰，下颌线条柔和但不过分尖锐，颧骨有适度体积；眼裂适中，眼神平静专注，鼻梁顺直，鼻尖微圆，嘴唇自然闭合。冷调白皙肤色，皮肤表面干净细腻，无明显瑕疵。深黑色中长直发，长度及肩下，中分刘海自然垂落两侧，发束整齐顺滑。身穿纯黑色直身剪裁外套，长度至大腿中部，窄翻领设计，单排深色纽扣门襟，袖口止于腕部露出手掌，下摆平整无开衩；外套材质为哑光细织纹呢料，表面干净细腻无反光。内搭深灰色简约衣物，下身搭配同色系修身长裤，脚穿黑色低帮平底鞋。白底柔和均匀展示光保留五官体积、衣料织纹和鞋面层次，轮廓与白底分离，面部不过曝，不用深影遮住结构；无额外首饰、图案、场景或文字。

**Status:** This character-prompt output was marked accepted by the product owner. That acceptance applies to the text prompt, not to an image generated by an external tool.

## Case 2 — A generated A-to-B motion prompt excerpt

The excerpt below is from a completed keyframe prompt run. Character names are anonymized. It is shown as an example of detailed motion wording, **not as an accepted quality result**:

> 0–4秒：国风二维动画；上色方式：赛璐璐平涂（采用清晰色块与赛璐璐式平涂上色）；色彩倾向：黑白灰阶（以黑白灰阶呈现明暗与层次）；明暗层次：柔和低反差（采用柔和、低反差的明暗处理）。摄影机从高处轻微俯角开始缓慢向前推进，同时轻微向右摇摄，降至人群视线高度的水平视角。随着镜头移动，前景人群的虚化程度增加，原本处于远景右侧角落的角色甲逐渐进入画面中心区域。角色乙保持静止，但头部随着视线引导微微抬起，身体略微转向右侧，眼神聚焦于画外右侧。环境光线稳定，空气中漂浮的微尘在光束中可见。殡仪馆内回荡的低沉哀乐，夹杂着压抑的抽泣声和衣物摩擦的细微声响，作为背景音平稳持续，音量保持不变，弥漫在整个空间中无明显单一声源。焦点逐渐锁定在角色甲身上，角色乙面部稍显柔和但仍可辨认，最终形成中景画面，左侧墙边的白色菊花装饰、右侧门框边缘、天花板吊灯底部和地面黑色地毯前缘构成画框边界。

**Status:** Generated and persisted; no human acceptance is claimed here. A generated text sample demonstrates output form, not external video quality or fidelity.

## What the comparison demonstrates

The source brief names a character and visual direction. The accepted output turns that brief into a copy-ready character description with a white background, frontal full-body framing, appearance, clothing, and presentation details. The motion excerpt demonstrates how camera movement, subject response, environment, sound, focus, and final framing can be expressed together.

This is a **format and detail comparison**, not a controlled before/after experiment. It does not prove fewer generations, a particular image/video quality, or a market ranking.
