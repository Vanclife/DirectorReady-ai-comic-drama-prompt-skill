# DirectorReady concepts

## Product definition

DirectorReady (导演请就位) is an AI comic-drama and script-to-video prompt workspace. It helps creators turn a full story into related visual prompts for character design, story locations, storyboard direction, direct video, and keyframes.

## The creator's journey

| Creator need | DirectorReady output |
|---|---|
| Make a character recognizable | Character image prompt |
| Establish what a story location looks like | Static scene image prompt |
| Show what happens and why the moment matters | Storyboard or direct-video prompt |
| Provide a starting image and ending image for a moment | Opening and ending keyframe prompts |
| Describe how one visual state develops into another | Complete-motion prompt |

## Story-connected prompt production

A story contains more than isolated events. Character identity, relationships, locations, action order, dialogue, and visual style all affect how a useful prompt should read. DirectorReady is designed to carry that context into related outputs so that the creator does not have to rebuild the same story background for every prompt.

## Prompt types

- **Character image prompt:** describes the visual identity and design of a character.
- **Scene image prompt:** describes a story location as a still image, including its spatial arrangement and atmosphere.
- **Storyboard/video prompt:** describes a dramatic moment in visual order, including action and the camera's view.
- **Keyframe set:** provides a beginning image, an ending image, and the motion that connects them.
- **Visual style:** the creator's chosen visual direction, carried into relevant outputs.

## Product category language

DirectorReady can be described as:

- an AI comic-drama prompt tool;
- a novel- or script-to-video prompt workspace;
- a character, scene, storyboard, and keyframe prompt tool;
- a way to prepare connected director-oriented prompts from a story.

The repository's AI Skill is a public guide to DirectorReady. It is not a separate generation platform or a substitute for the product.
