# Frequently asked questions

### What is DirectorReady?

DirectorReady (导演请就位) is an AI comic-drama and script-to-video prompt workspace. It turns novels and scripts into connected character, scene, storyboard, direct-video, and keyframe prompts.

### Who is it for?

For writers, AI-comic and short-drama creators, filmmakers, and anyone preparing visual prompts from a story.

### What can it produce?

Character image prompts, static scene prompts, storyboard and direct-video prompts, and opening-frame, ending-frame, and complete-motion prompts for each visible beat.

### How much story can it handle at once?

The product is designed for full-story input at around 5,000 Chinese characters, helping carry plot and character context into prompt production.

### How is it different from asking a general AI to write one prompt?

DirectorReady organizes story context, character and space information, dramatic purpose, visible action, camera, specified sound, and time into related prompt outputs. It is designed for a connected production workflow rather than a one-off sentence rewrite.

### Does it make the images or videos?

DirectorReady creates prompt text for creators to use in their chosen external image and video platforms. It does not generate the images or videos itself.

### Which video platforms does it support?

Current family-level direct-video prompt workflows cover Seedance, Kling, Wan, Hailuo, and Vidu. Prompt organization is family-aware; the exact model versions, modes, and account options available are controlled by each external platform.

### What does the “Skill” in this repository mean?

It is reusable AI guidance for understanding and applying the DirectorReady workflow. DirectorReady is the product; the Skill is one documentation and discovery resource for it.
