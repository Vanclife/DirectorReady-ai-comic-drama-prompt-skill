# Video model-family compatibility

DirectorReady keeps one story direction and organizes its expression for the selected video-model family. The current family-level prompt workflows are:

| Family   | Prompt use                      |
| -------- | ------------------------------- |
| Seedance | Direct-video prompt composition |
| Kling    | Direct-video prompt composition |
| Wan      | Direct-video prompt composition |
| Hailuo   | Direct-video prompt composition |
| Vidu     | Direct-video prompt composition |

This is a family-level compatibility statement. A platform may offer multiple models, versions, input modes, settings, or account-specific features; those options are maintained by the platform and can change over time. The creator selects the external entry and uses the generated text there.

## What stays consistent

- story facts and character identity;
- selected visual style;
- dramatic purpose and action order;
- camera and spatial direction already established for the prompt;
- specified dialogue, sound, and timing.

## What adapts

The ordering, emphasis, and natural-language organization used to communicate the same direction to a target family. DirectorReady uses family-specific prompting guidance rather than assuming that every platform interprets identical prose in the same way.
