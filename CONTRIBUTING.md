# Contributing

Contributions that make DirectorReady easier to understand and use are welcome.

## Good contributions

- improve product explanations without changing the product's documented capabilities;
- clarify prompt concepts or add an original, clearly labeled example;
- report a broken link, typo, outdated platform reference, or confusing workflow description;
- add an evaluation case that tests a real user request.

## Before submitting

1. Explain the user need the change addresses.
2. Keep product facts consistent with the current documentation.
3. Label illustrative examples as examples; do not present them as customer results.
4. For model-family information, link to a current official platform source and include the date checked when details may change.
5. Do not include private scripts, personal data, API credentials, or unpublished customer material.

Please open an issue or pull request with a concise description of the proposed change.
