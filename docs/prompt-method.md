# A creator-facing map of prompt content

This page explains the kinds of information that may appear in DirectorReady outputs. It is a creator-facing overview, not a fixed template for every platform.

## Character image prompt

A character prompt helps an artist or image model understand a recognizable design. Depending on the source story and selected style, it can describe identity, face and body, hair, clothing, footwear, accessories, materials, colors, and the intended composition. The current character-image presentation uses a frontal full-body figure on a pure white background, standing naturally with hands relaxed at the sides.

## Scene image prompt

A scene prompt describes one static story location. Useful details can include the location, layout, foreground and background, depth, paths and openings, landmarks, visible architecture, objects, materials, color, lighting, and atmosphere. It is a prompt for the environment as a visual reference.

## Storyboard and direct-video prompt

A video-oriented prompt can communicate what the moment means, who is visible, what happens and in what order, how the camera sees it, how the environment changes, and how specified dialogue or sound fits the moment. Timing and the resulting image state can help make the action understandable as it unfolds.

The same story direction can be arranged for different model families. The writing should remain natural and useful to the selected external platform, while preserving the story's intended content.

## Keyframe prompt set

For one visible beat, the related outputs are:

- an opening image prompt for the starting still;
- an ending image prompt for the final still;
- a complete-motion prompt describing the visual transition between them.

The motion prompt can cover physical action and state changes as well as camera, environment, and specified sound. It should describe the whole transition, not only the camera movement.

## Connected outputs

When prompts come from the same story, character appearance, location, action order, and selected style should remain understandable across the set. Each prompt should also be clear enough to copy into the creator's intended external workflow.
