# DirectorReady workflow

DirectorReady takes a story-first route from a novel or screenplay to practical visual prompts for external creation tools.

```text
Full novel or screenplay (around 5,000 Chinese characters)
        ↓
Understand the story, characters, and locations
        ↓
User's visual-style selection
        ↓
Character design prompts + scene prompts
        ↓
Storyboard and timed visual direction
        ↓
Model-family-aware direct-video prompts
        ↓
Per-beat opening image + ending image + complete motion prompt
        ↓
Copy prompts into the creator's chosen external platform
```

## 1. Bring in the story

The story provides characters, facts, dialogue, dramatic events, and locations. DirectorReady is designed for a full-story input so later prompts can retain the right context instead of treating each line as an isolated idea.

## 2. Set the visual direction

The creator selects a visual style. That choice guides applicable character, scene, and video prompts, so the output belongs to a coherent visual world.

## 3. Build reusable visual references

Character prompts establish recognizable appearances. Scene prompts establish the layout and visual character of story spaces. Both help creators carry a consistent world into later video work.

## 4. Direct the story in time

Story moments are organized into visual direction. Action, camera, environment, and specified sound can be described together in time, making the prompt explain a developing moment rather than present only a collection of visual adjectives.

## 5. Organize for the target video family

The direct-video workflow organizes the same intended story direction in a form suited to the selected model family. The family-specific arrangement helps communicate the direction; the story remains the source of meaning.

## 6. Create keyframes and motion

For each visible beat, DirectorReady supplies an opening still, an ending still, and the complete motion that connects them. The prompts stay associated with the beat they describe.

## 7. Use the prompts where you create

The resulting text is ready to copy into the creator's chosen image or video platform. DirectorReady focuses on prompt production and story-to-visual organization; actual media generation takes place in the external platform.
